# 📖 本地多PDF文档智能问答系统
基于 **LangChain + 通义千问大模型** 实现的本地RAG智能问答系统，支持批量加载PDF文档、多轮对话记忆、自动标注引用来源，告别AI幻觉，让问答结果有据可依。

---

## ✨ 核心功能
✅ **多PDF文档批量加载**：自动读取 `docs` 文件夹内所有PDF文件，无需手动指定  
✅ **向量库持久化**：首次生成向量后自动保存，后续启动无需重复加载文档  
✅ **多轮对话记忆**：支持上下文关联追问，像正常聊天一样对话  
✅ **引用来源标注**：每道回答自动显示参考的PDF文件名，杜绝AI编造  
✅ **网页可视化界面**：基于Gradio构建浏览器端聊天界面，告别黑终端  
✅ **严格文档约束**：仅基于提供的PDF内容回答，超出范围直接说明

## 🚀 快速开始
### 1. 环境准备
确保你的电脑已安装Python 3.8及以上版本，建议使用虚拟环境运行项目。

### 2. 安装依赖
```bash
pip install langchain langchain-community langchain-openai langchain-text-splitters chromadb pypdf dashscope gradio
```

### 3. 获取通义千问 API Key
前往阿里云百炼控制台注册登录
进入「API Key 管理」，创建并复制你的 API Key（格式为sk-xxxx）

### 4. 配置项目
打开项目根目录的 rag_demo.py，找到配置区，替换为你的 API Key：
```bash
# ===================== 配置区（只改这里！）=====================
API_KEY = "你的通义千问API Key"  # 替换为自己的密钥
DOCS_FOLDER = "./docs"           # PDF文档存放文件夹
VECTOR_DB_PATH = "./chroma_db"   # 向量库本地保存路径
# ==============================================================
```
### 5. 准备文档
在项目根目录创建 docs 文件夹（已自动生成），将你需要问答的 PDF 文档放入其中，支持子文件夹嵌套。

### 6. 启动服务
执行以下命令运行项目：
python rag_demo.py
程序会自动生成向量库（首次运行），并弹出浏览器网页界面，地址为 http://127.0.0.1:7860。

## 💡使用说明
### 1.首次运行：
程序会自动加载 docs 文件夹内的所有 PDF，生成向量库并保存到 chroma_db 文件夹，下次启动无需重复生成。
### 2.提问方式：
在网页输入框输入问题，支持直接提问或上下文追问，例如：
·问题 1：大模型应用开发流程有哪几步？
·问题 2：帮我把步骤精简成三句话
### 3.引用来源：
回答末尾会自动标注参考的 PDF 文件名，例如：📚 引用来源：大模型应用开发入门指南.pdf
### 4.清空对话：
点击「清空对话」按钮，可重置当前对话历史。

## ❓ 常见问题
### Q1：程序运行时提示 “未找到相关内容”
检查你的问题是否在 PDF 文档的内容范围内
确认 PDF 文档已放入 docs 文件夹，且文件格式正确
首次添加新文档后，需删除 chroma_db 文件夹，重新运行程序生成新的向量库
### Q2：API Key 相关报错
检查 rag_demo.py 中的 API Key 是否正确，格式为 sk-xxxx
确认你的通义千问账号有可用额度，API Key 未过期
检查网络是否能正常访问阿里云百炼服务
### Q3：网页界面打不开 / 报错
确认程序运行正常，终端显示 Running on local URL: http://127.0.0.1:7860
关闭代理 / VPN，避免影响本地服务访问
若 Gradio 版本不兼容，可尝试执行 pip install gradio==4.0.0 降级安装
